# Web 逆向 HTML 报告规范

单文件、内联 CSS（用 `{skill_dir}/assets/report.css`，可追加少量自定义类）。
命名 `<YYYYMMDD>-<HHmm>-web-deep-reverse.html`，写当前工作目录，完成后 `open` 并告知路径。

---

## 第一原则：外行能看懂

报告读者往往**不是安全工程师**，可能是产品、法务、老板，或者一个刚学会用命令行的开发者。
一份只有术语堆砌的报告等于没写。强制要求：

1. **每个专业名词第一次出现时，用一句人话解释**
   - ❌ "签名采用 ECDH 派生密钥"
   - ✅ "签名用了一种'双方各自算一下就能得到同一把钥匙'的算法（ECDH），钥匙从不出现在网络上"
2. **类比优先**：DNS=电话簿、边缘节点=连锁便利店、回源=缺货调货、GSLB=会算命的户籍警
3. **先结论后原理**：每章开头一段"这章回答什么问题"，结尾一段"所以呢"
4. **必须有一张三分钟流程图**，让不读正文的人也能看懂链路
5. **代码块必须有注释说明它在证明什么**，不要裸贴日志

---

## Header 必标

- 目标 URL / 站点名
- **证据级别**（勿夸大）：仅静态资源 / 静态+签名复现（未重放）/ 含接口重放（注明已授权）/ 含流媒体验证
- **重放状态**：完成 / 部分 / 未执行（原因：未授权 / 无需）
- 生成时间与工作目录

---

## 章节结构（顺序固定）

```
零、三分钟版          ← 一句话结论 + 一张流程图 + 关键数字
一、概念科普          ← 内联 assets/concept-glossary.md（可裁剪）
二、基本信息与技术栈
三、接口清单
四、签名与加密算法    ← 含算法还原 + 验证样例（真实请求 vs 复现结果）
五、密钥与配置表      ← 名称→值→来源→分级（硬编码/接口下发/会话级/不可得）
六、流媒体与 CDN      ← 三层验证记录 + 四证交叉 + 多视角解析表
七、踩坑实录          ← 现象→原因→解法（真实经历，禁止编造）
八、安全评估          ← 防护措施→绕过难度→影响
九、复盘与产物        ← 步骤、跳过项、耗时、文件清单
Footer：对象/时间/工具/「仅用于技术研究与学习目的」
```

## 各章要点

### 零、三分钟版
- 一句话说清"这个站怎么保护、我们破了什么、拿到了什么"
- 一张 ASCII 流程图（请求 → 签名 → 接口 → 流地址）
- 3–5 个关键数字（主包大小、VM 大小、接口数、流码率等）

### 一、概念科普（新增，强制）
直接内联 `assets/concept-glossary.md`，按需裁剪。至少覆盖：

- 域名 / IP / DNS（递归服务器 vs 权威服务器 / CNAME / TTL）
- CDN 与边缘节点（含"回源"）
- GSLB 调度器与 ECS
- 负载均衡 CLB 与 GSLB 的区别
- 跨境专线（说明何时与本次分析无关）
- 术语速查表

### 四、签名与加密算法
- 先用 2–3 句话讲"它在防谁"（防脚本小子，不防逆向）
- 再给算法伪代码
- 再给**三重验证**：① 运行时 trace ② 宿主化/离线复现 ③ 纯实现打生产接口（含必败用例）
- 每个结论后跟证据（文件、行号、请求样例）

### 六、流媒体与 CDN
- 三层结构（主清单 → 子清单 → 分片）逐级验证，标注 HTTP 状态与文件类型
- **四证交叉表**（CNAME / NS / Header / ASN）
- **多视角解析表**（海外 + 大陆 ≥3 地），明确写"在该解析视角下"
- 若只有单一视角 → 必须标「未做多视角验证」

### 七、踩坑实录（新增，强制）
表格：`现象 | 真实原因 | 解法`。只写本次真实发生的，宁少勿编。至少 5 条。

### 八、安全评估
三列：防护措施 / 绕过难度 / 影响。最后一段给"正确加固方向"。

---

## 内容纪律

- 中文；技术名保留原文
- 每个结论带证据（URL、文件名、代码片段、请求样例）
- **禁止**把其他案例的密钥/token/域名抄进当前报告
- 未做重放就标「未执行」，不要编响应数据
- 响应体只摘关键字段，不整段贴（可能含他人数据）
- **否定性证据也要写**：403/空响应/未探明的门槛，如实标注
- 涉及 GSLB 的结论必须带视角限定语

---

## 视觉建议（提升可读性）

| 元素 | 用法 |
|---|---|
| `summary-box` | 每章开头的"一句话结论" |
| `warn-box` | 易误解点、需注意的前提 |
| `danger-box` | 安全弱点、设计缺陷 |
| `tag-*` | 分级标签（硬编码/接口下发/会话级） |
| `<pre>` ASCII 流程图 | 链路示意，比文字快 10 倍 |
| 表格 | 对比、清单、证据矩阵 |

编写时优先"一屏一个意思"：长段落拆成列表，术语密集处插一个类比。
